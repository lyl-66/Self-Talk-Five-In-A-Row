# Self-Talk-Five-In-A-Row

**五子棋 · 人机对战** —— 用 Godot 4.7 + GDScript 写的单人对战五子棋。

一个正方形的棋盘主窗口，外加两个可以各自关掉、独立存在的小窗口（比分、对话）。比分长期保存在你的用户目录里，电脑每落一子还会说一句话。

## 玩法

- 15 × 15 棋盘，在交叉点落子
- 你执黑先手，电脑执白
- 横、竖、斜任意方向先连成五子者胜，棋盘下满判和棋
- 自由规则，无禁手（长连也算胜）

操作：鼠标移到交叉点上会显示半透明预览，左键落子。棋盘上那个红点是电脑的最后一手。

## 运行

需要 [Godot 4.7](https://godotengine.org/download)：

```bash
godot --path .
```

或者用编辑器打开 `project.godot` 后按 <kbd>F5</kbd>。

## 三个窗口

| 窗口 | 默认尺寸 | 说明 |
| --- | --- | --- |
| 主窗口 | 720 × 720 正方形 | 棋盘 + 一行状态提示 + 三个按钮（比分窗口 / 重新开始 / 对话窗口） |
| 比分窗口 | 320 × 212 | 累计比分（我 / 电脑 / 和棋）和最近一局摘要，可清空 |
| 对话窗口 | 340 × 240 | 电脑每落一子在这里说一句 |

三个窗口的共同行为：

- **都能自由缩放**，各自设了最小尺寸，拖不到把内容切掉的程度
- **启动时回到上次的位置和开关状态**：上次关掉的小窗口这次仍是关着的，点主窗口对应按钮就能打开
- 第一次启动（还没有记录时）两个小窗口会摞在主窗口右边，**不会互相叠着**；屏幕右边放不下就自动挪到主窗口下方

主窗口放大缩小时棋盘整体等比缩放（窗口不是正方形时四周留边）；两个小窗口则是内容跟着重排，不缩放。

## 电脑的下法

启发式评估，没有搜索树，所以几乎是瞬时出招。优先级从高到低：

1. 自己能连五 → 直接赢
2. 对手能连五 → 必堵
3. 自己能做活四 → 对手堵不住
4. 对手能做活四 → 先用冲四抢先手，否则堵住
5. 其余情况按棋型分值（活四 / 冲四 / 活三 / 跳三 / 眠三 / 活二 …）挑攻守兼备的点，
   再对靠前的 16 个候选点推演一步，避免走出让对手立刻成势的棋

棋力参考：对随机落子约 10 手取胜；两个相同的实例互下会走成满盘和棋——防守很稳，但它只有一层推演，做出「四三」这类复合威胁仍有机会赢它。

## 思考时长

刻意做得不像机器，分三档：

| 情况 | 等待时间 |
| --- | --- |
| 电脑决胜的一手（这一手就能连五） | 0.15 秒短停顿 |
| 必须堵你的一手 | 0.4 ～ 0.9 秒随机 |
| 普通手 | 按局面紧张度在 0.1 ～ 10 秒之间 |

「紧张度」取全盘候选点里双方一手能做出的最大棋型，再按盘上棋子数压缩开局阶段，所以开局下得快、关键处明显变慢。

## 让电脑说话

| 想做的事 | 怎么做 |
| --- | --- |
| 换台词 | 改 `talk_window.gd` 顶部的 `PLACEHOLDER_LINES`；台词里可用 `{move}`（第几手）和 `{cell}`（落点，如 `H8`），用不用哪个都行 |
| 让一段话分几手说完 | `talk_window.queue_passage("第一句\n第二句\n第三句")`；之后电脑每次落子**只取一行**，整段说完自动回到占位台词 |
| 调整日志长度 | `talk_window.gd` 的 `MAX_LINES`（默认 200 行，超了丢最老的） |

每落一子说一句的调用点在 `main.gd` 的 `_run_ai_turn()` 里。

## 成绩与存档

三个文件都在同一目录，Windows 上是：

```
%APPDATA%\Godot\app_userdata\Self-Talk-Five-In-A-Row\
```

| 文件 | 内容 |
| --- | --- |
| `score.cfg` | 总比分和总局数（ConfigFile 文本格式，可手改、可手抄） |
| `history.jsonl` | 每局一行 JSON：`{"time":"2026-09-27T14:03:11","result":"player","moves":43}`，`result` 取 `player` / `ai` / `draw` |
| `windows.cfg` | 三个窗口的位置、尺寸、开关状态 |

几点说明：

- **备份**就是复制这三个文件；**清空比分**用比分窗口里的「清空」按钮（有二次确认），旧明细会改名成 `history-<时间>.jsonl` **留档而不是删除**
- 目录名取自 `project.godot` 里的 `application/config/name`，所以**改工程名会让存档看起来「被清零」**（其实是换了目录，老文件还在原处）
- 读取一律容错：文件缺失、被改坏、字段类型不对，都当作 0 或默认值处理，不会让游戏崩
- 记录里的窗口位置如果落在所有显示器之外（比如拔掉了副屏），会被夹回主显示器，不会开到看不见的地方

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `gomoku.gd` | 规则：棋盘尺寸、坐标换算、五连判定 |
| `ai.gd` | 电脑走子：棋型分值表、硬规则、紧张度估计 |
| `board.gd` | 棋盘视图：绘制、点击取点、悬停预览 |
| `main.gd` | 对局流程：轮流落子、判胜、记录比分、三档思考时长、窗口摆放 |
| `score_store.gd` | 比分存档的读写（总分 + 每局明细，原子写入 + 容错读取） |
| `score_window.gd` / `.tscn` | 比分窗口 |
| `talk_window.gd` / `.tscn` | 对话窗口（含台词队列） |
| `window_layout.gd` | 窗口布局存档的读写 |
| `main.tscn` | 主场景：棋盘、状态文字、三个按钮、两个窗口实例 |

## 想改手感

| 位置 | 作用 |
| --- | --- |
| `main.gd` 的 `AI_THINK_DELAY_*` | 三档思考时长 |
| `ai.gd` 的 `PATTERNS` | 棋型分值表，按威胁从大到小排列 |
| `ai.gd` 的 `_threat_level()` | 棋型分值 → 紧张度档位 |
| `ai.gd` 的 `SEARCH_WIDTH` | 一步推演考察多少个候选点 |
| `board.gd` 的 `CELL` / `MARGIN` | 棋盘格距与留白 |

## 环境

Godot 4.7.2（Forward+ 渲染，Direct3D 12）。

- 主窗口 720 × 720，`canvas_items` 拉伸 + 保持比例，所以缩放窗口时棋盘等比跟随
- 两个小窗口靠 `display/window/subwindows/embed_subwindows=false` 才是**真正独立的系统窗口**，能单独最小化、关闭
- 界面中文用系统字体（微软雅黑 / 思源黑体 / 黑体）渲染，因为 Godot 默认主题字体不含中文字形
