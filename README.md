# 五子棋 · 人机对战

用 Godot 4.7 + GDScript 写的单场景五子棋，你对电脑。界面极简：一块棋盘、一行状态提示、一个「重新开始」按钮。

## 玩法

- 15 × 15 棋盘，在交叉点落子
- 你执黑先手，电脑执白
- 横、竖、斜任意方向先连成五子者胜，棋盘下满判和棋
- 自由规则，无禁手（长连也算胜）

操作：鼠标移到交叉点上会显示半透明预览，左键落子。围棋盘上那个红点是电脑的最后一手。

## 运行

需要 [Godot 4.7](https://godotengine.org/download)：

```bash
godot --path .
```

或者用编辑器打开 `project.godot` 后按 <kbd>F5</kbd>。

## 电脑的下法

启发式评估，没有搜索树，所以几乎是瞬时出招。优先级从高到低：

1. 自己能连五 → 直接赢
2. 对手能连五 → 必堵
3. 自己能做活四 → 对手堵不住
4. 对手能做活四 → 先用冲四抢先手，否则堵住
5. 其余情况按棋型分值（活四 / 冲四 / 活三 / 跳三 / 眠三 / 活二 …）挑攻守兼备的点，
   再对靠前的 16 个候选点推演一步，避免走出让对手立刻成势的棋

棋力参考：对随机落子约 10 手取胜；两个相同的实例互下会走成满盘和棋——防守很稳，但做出「四三」这类复合威胁仍能赢它。

## 思考时长

刻意做得不像机器，分三档：

| 情况 | 等待时间 |
| --- | --- |
| 电脑决胜的一手（这一手就能连五） | 0.15 秒 |
| 必须堵你的一手 | 0.4 ～ 0.7 秒随机 |
| 普通手 | 按局面紧张度在 0.1 ～ 10 秒之间 |

「紧张度」取全盘候选点里双方一手能做出的最大棋型，再按盘上棋子数压缩开局阶段，所以开局下得快、关键处明显变慢。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `gomoku.gd` | 规则：棋盘尺寸、坐标换算、五连判定 |
| `ai.gd` | 电脑走子：棋型分值表、硬规则、紧张度估计 |
| `board.gd` | 棋盘视图：绘制、点击取点、悬停预览 |
| `main.gd` | 对局流程：轮流落子、判胜、状态文字、思考时长 |
| `main.tscn` | 唯一场景，三个节点（棋盘 / 状态文字 / 按钮） |

## 想改手感

| 位置 | 作用 |
| --- | --- |
| `main.gd` 的 `AI_THINK_DELAY_*` | 三档思考时长 |
| `ai.gd` 的 `PATTERNS` | 棋型分值表，按威胁从大到小排列 |
| `ai.gd` 的 `_threat_level()` | 棋型分值 → 紧张度档位 |
| `ai.gd` 的 `SEARCH_WIDTH` | 一步推演考察多少个候选点 |

## 环境

Godot 4.7.2（Forward+ 渲染，Direct3D 12）。窗口 600 × 780，`canvas_items` 拉伸模式，缩放窗口时棋盘等比跟随。界面中文用系统字体（微软雅黑 / 思源黑体 / 黑体）渲染，因为 Godot 默认主题字体不含中文字形。
