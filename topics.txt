// ============================================================
//  台词文件。把下面的示例换成你自己写的内容就行。
//
//  格式：
//    ### 话题：标题        开始一个普通话题（可以写很多个，每局随机抽一个）
//    ### 特别话题 3：标题   开始一个「特别话题」，编号 1～5，见下面
//    一行一句台词           话题正文，对手每落一子说一句；写多长你自己定
//    === 垫场              正文说完之后的垫场句池（所有话题共用）
//    === 结束 32 玩家赢     本局在 32 子以内结束、而且是玩家赢了时说的告别语
//    === 结束 32 玩家输     同上，但是玩家输了
//    === 结束 32           不写胜负标记，就是两种结果都能用的兜底句
//
//  话题怎么选：
//    · 普通话题**随机抽**，而且一轮之内不会重复——全部抽过一遍才重新洗牌重来。
//    · 玩家第 N 次赢之后的**下一局**，固定说「特别话题 N」（N = 1～5）。
//      所以特别话题是按顺序一个个放出来的，每个只说一次。
//      五次之后（或者没写到的编号）就回到随机。
//    · 只写 1、2、3 也没关系：第 4、5 次赢之后照样随机。
//    · 对话窗口还锁着的时候（还没赢过第一把）不开话题，也不算抽过。
//
//  档位固定为 10 / 16 / 24 / 32 / 64 / 128 / 256（本局一共下了多少颗子），
//  写哪个都行；没写的档位会自动往更大的档找。
//  建议句数递减，例如：结束 10 每边 10 句、16 → 9 句、24 → 8 句、32 → 7 句……
//
//  棋盘一共 225 个点，所以 256 这一档其实一辈子不会正好卡上，
//  它的意思是「128 子以上、以及满盘和棋都归这里」，一般只写一行不带标记的。
//
//  台词里可以用的变量（用不到的可以不写）：
//    {move}         当前总手数
//    {cell}         对手这一手的落点，如 H8
//    {player_move}  玩家上一手的落点
//    {my_score}     对手累计胜场     {player_score} 玩家累计胜场
//    {draws}        和棋数           {topic}        话题名
//
//  以 // 开头的行是注释，不会说出来。空行会被忽略。
//  把这份文件放到用户目录（同名 topics.txt）就会优先用你的那份，
//  不用改工程、也不用重新导出；改完下一局自动生效。
//  文件有问题（档位写错、标记认不出、变量名拼错）会显示在对话窗口底部。
// ============================================================

=== 垫场

唔……这手不太好下。
{player_move} 那边我记着了。
